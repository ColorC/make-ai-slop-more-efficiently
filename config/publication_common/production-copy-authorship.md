# 生产级中文文字决策手册

适用范围：个人网站、小红书、公开文章、游戏文本、产品界面、运营内容、商店文案、提示信息、对外报告，以及任何可能被外部用户看到或作为正式产品资产交付的中文文字。

## 唯一作者

生产级中文文字只允许由模型策略登记的成文模型独立生成。当前可选模型为 the_company 网关的 `qwen3.7-max`、`deepseek-v4-pro`、`kimi-k2.6` 与 Kimi 直连端点的 `k3`；未显式指定时默认使用 `qwen3.7-max`，每次成稿的 Agent tag 必须写出实际 API 模型 ID。

ChatGPT、Codex、Claude Opus、Claude Fable 及其他未被本次任务选为成文作者的 Agent 禁止：

- 直接撰写、改写、润色或续写生产级中文；
- 先写母稿、事实稿、内容 brief、提纲、标题、建议句或图卡文字，再交给成文作者改写；
- 用摘要、效果矩阵、叙事结论或人物动机替成文作者预先解释材料；
- 在视觉实现过程中临时补标签、标题、批注、图注、按钮文案或封面字。

这项限制不妨碍 Codex、Claude 编写内部操作文档、代码、测试、HTML/CSS 和只供机器消费的确定性结构；只要这些内容不会作为生产级中文呈现给外部用户。

## 允许交给成文作者的输入

每次正式成文只给本次选定的成文作者：

1. 目的和使用场景；
2. 当前有效的规范与平台边界；
3. 静态材料目录；
4. 需要保持连续性时，已经公开内容的原文或同一作者会话的成稿原文。

静态材料目录允许包含：

- 原始文件路径或公开 URL；
- 行号、页码、时间点、界面区域或提交差异范围；
- 材料类型、创建/采集时间和当前状态；
- 对材料本身的中立客观说明，例如“该文件保存用户逐字反馈”“该截图是发布前后界面对照”；
- 公开边界和待确认标记。

中立说明只能描述材料是什么，不能解释材料意味着什么。目录禁止包含：

- 因果、动机、情绪、收益、重要性和效果判断；
- 选题结论、叙事顺序、文章结构、推荐标题和建议措辞；
- 把多个来源拼接成的二手故事；
- 由其他模型写出的公开候选文本。

## 分工

| 工作 | Codex / Claude | 本次选定的成文作者 |
|---|---|---|
| 找文件、原话、截图和运行记录 | 允许 | 允许自行回源 |
| 建静态材料目录 | 允许，只能中立描述材料本身 | 可读取并继续探索 |
| 事实核验与隐私检查 | 允许，只报位置、类型和证据 | 根据报告回源后自行修改 |
| 标题、正文、图卡文字、界面文案 | 禁止 | 唯一作者 |
| 截图、裁切、圈画、版式、HTML/CSS | 允许 | 可提出自己的文字承载需求 |
| 修改公开中文 | 禁止提供替换句 | 原作者会话续修 |

## 图文契约

- 成文作者先把所有可见文字写入明确的文字源文件。
- 视觉实现者只负责资产、结构、布局、样式和渲染，并逐字装配文字源。
- 若版面需要新增标签、缩短标题或改变图注，视觉实现者记录需求并退回同一个作者会话；不得自行改字。
- 渲染检查必须比较最终可见文字与作者文字源。任何新增、删减或替换都阻断交付。

## 返修契约

- 机械问题由确定性工具修复。
- 事实或语义问题交回原作者会话，输入只含问题位置、问题类型、用户原话和一手证据路径/切片。
- 核验员不写建议句，不代替成文作者总结文章问题，也不另起新模型从头重写。
- 需要拆篇时，把完整材料目录交给成文作者，由成文作者自己决定每篇的中心、结构和表达。

## 硬门

- [ ] 生产级中文的最终作者模型属于登记的可选模型，并与本次请求和 Agent tag 一致。
- [ ] 输入包没有母稿、事实稿、内容 brief、效果矩阵、推荐提纲或其他模型的候选文本。
- [ ] 静态目录的说明只描述材料本身，没有解释或结论。
- [ ] 标题、正文和全部视觉文字均有本次成文作者的源文件。
- [ ] Codex / Claude 的改动只涉及材料索引、事实定位、代码、视觉结构与确定性检查。
- [ ] 语义返修发生在原作者会话。
