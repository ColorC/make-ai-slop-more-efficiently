# 完整事实母稿

此文件先用自然语言讲完整，再做载体选择。禁止预设字数、卡片数或平台容量：过早压缩会让句子失去主语、背景、因果和解释，最终出现语法勉强成立但读者无法理解的短语。母稿超过单篇容量时，解决方式是合理拆篇、改发长文或把一个完整分支做成阅读扩展图，不能回头破坏母稿的语言。

## 1. 到现在具体做成了什么

列出当前可观察产物、入口、能力、适用对象和真实状态。

## 2. 读者理解这些产物需要什么背景

只补本文必需背景；项目名、缩写和内部命名首次出现时解释。

## 3. 关键案例

每个案例按“对象 → 背景 → 动作 → 问题 → 修正 → 结果 → 边界”展开。数字紧跟口径。专有名词、代称和例子逐项判断陌生读者能否理解；例如“删除戏剧故事”必须说明故事写了什么、原材料为什么不支持、最后怎样处理。

## 4. 可以带走的经验

每条经验紧邻支撑它的案例，说明适用条件。不能把 Agent 的编辑判断写成 ColorC 的动机。

## 5. 当前限制与下一步

写清尚未完成、尚未验证、当前接口没有覆盖的部分。

## 6. 可视化与演示素材

列出适合图卡的结构、适合视频的动态过程、适合正文的连贯说明和必须保留的证据。
