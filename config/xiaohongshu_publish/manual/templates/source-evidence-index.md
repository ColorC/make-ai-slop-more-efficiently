# 静态材料目录

本文件只帮助本次选定的发布 Agent 定位原始材料。可以中立说明材料本身是什么，不能解释材料意味着什么，不写跨来源总结，不替作者解释动机，不把多个事件拼成故事。

前置搜集可由 `claude_code/sonnet` 或 `codex/gpt-5.6-terra` 完成。无论使用哪一个，发布 Agent 都必须沿路径回读原文后再写公开稿。

## 禁止项

- 不写“这说明”“其目的是”“因此决定”等推导句。
- 不把提交号、对话 ID、内部页面名直接搬进公开稿。
- 不用二手摘要替代原话；找不到原始位置时标记“尚未确认”。
- 不给写作 Agent 预制情绪、标题、结论或叙事顺序。
- 不复制另一个模型写出的候选正文、母稿、事实稿、brief、提纲和建议句。
- 中立说明只能写“文件保存了什么类型的材料”，不能写“这说明什么、为什么重要、适合怎么写”。
