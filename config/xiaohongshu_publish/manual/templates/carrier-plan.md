## 候选载体

| 载体 | 适合承载 | 当前容量风险 | 接口是否已接通 | 结论与理由 |
|---|---|---|---|---|
| 普通图文 | 结构摘要、有限案例、静态证据 | | | |
| 长文 | 完整论证、多个连续案例 | | | |
| 视频 | 操作演示、页面变化、时间过程 | | | |
| 系列帖 | 多个可以独立回答的问题 | | | |

## 最终选择

- 载体：
- 单篇中心：
- 是否分篇：
- 正文承担：
- 图片承担：
- 视频承担：
- 可公开真实素材清单：
- 图卡分镜（信息任务 / 内容模式：演示图或阅读扩展 / 相对正文新增信息 / 素材来源 / 主版式）：
- 只看图片能否复述主线：
- 图文重复检查：
- 专名与案例解释检查：
- 语义断行检查：
- 版式重复率检查：
- 被删内容及原因：
- 关键正文字号：不低于 42px
- 标题字号：通常不低于 64px
