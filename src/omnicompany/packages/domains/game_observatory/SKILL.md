# Game Observatory

Use the domain CLI and API to collect, validate, and review public game-system evidence.

1. Read `README.md` for the current CLI, API, storage, and authentication contracts.
2. Prefer existing fixtures and read-only catalog queries before requesting a live capture.
3. Run live device control or capture only when the user explicitly places that device in scope.
4. Keep canonical evidence and revisions append-only; publish through the redacted projection.
5. Report incomplete benchmarks, unavailable devices, and unverified gameplay routes as limitations.
