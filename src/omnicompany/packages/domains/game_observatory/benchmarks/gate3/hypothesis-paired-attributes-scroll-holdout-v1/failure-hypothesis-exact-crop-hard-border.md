# Gate 3 失败假设：精确裁片边界不够显式

## 观察

`hypothesis-run-06` 首次完成“框选—裁片送达—同框提交”闭环。右侧精确裁片没有额外边框，多个数值在裁片右缘被截断；模型仍把完整原图中看到的后缀补入 `visible_cue`。

## 可证伪假设

若给精确裁片自身绘制高对比红色硬边界，并明确标出只有该红框内像素可写成框内线索，模型会扩大并重新检查目标框，或只描述裁片中完整可见的纹理、线条与字符，不再从完整原图补齐边界外文本。

## 重跑判据

- 精确裁片面板带红色闭合边框和硬限制标签。
- 最终 `visible_cue` 中的每个完整字符串都能在红框内逐字看到。
- 若文本被切断，只允许描述可确认的部分或非文字视觉线索。
