# Gate 3 失败假设：框外文字缺少邻接几何合同

## 观察

`hypothesis-run-08` 的 region OCR 白名单成功拒绝三次错误，并在运行时重试后移除了框内数字声明。最终 `visible_cue` 又把完整图最左侧的“生命值、攻击力”写成窄走廊的“框外左侧相邻”文本；这些文字距离目标框约 400 像素，不在 64 像素检查上下文内。

## 可证伪假设

将 OCR 文字来源拆成 `visible_text_tokens` 与 `adjacent_text_tokens`，后者只接受检查上下文内、完整位于目标框外且不跨越框边界的 token，再用完整截图 OCR 词表发现所有未声明 UI 原文，可确定性阻止远距离文字被伪装成邻接锚点。

## 重跑判据

- region manifest 保存框内、邻接上下文、完整截图三层 OCR token。
- 最终建议显式提供两个结构列表。
- 本走廊的框内和邻接列表均为空；`visible_cue` 不得出现生命值、攻击力或任何其他完整 UI 原文。
- 允许保留“左侧有属性名称列”等不逐字转写的结构描述。
